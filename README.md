# Mixture-of-Facets (MoF)

Official implementation of **Mixture-of-Facets (MoF)**.

MoF is a scalable personalization framework for black-box LLMs. Instead of maintaining a separate scoring head for every user, MoF represents user preferences as compositions of shared latent preference facets and dynamically combines them through history-conditioned routing.

This design provides two key advantages:

* **Scalable personalization**: the number of personalized parameters does not grow with the number of users.
* **Unseen-user generalization**: new users can be personalized from their interaction histories without additional parameter updates.

## Overview

MoF follows a reranker-and-adapter framework for black-box LLM personalization.

Given a user's interaction history, MoF constructs a preference representation and uses a preference-aware router to select and combine shared facet heads. A sparse autoencoder (SAE) is used to encourage preference-relevant user representations, while cluster-based sampling promotes specialization across different preference facets.

The framework is applied to both:

* **Reranker**: selects useful items from the user's history.
* **Adapter**: ranks candidate responses generated by the black-box LLM according to the user's preferences.

## Data

Experiments use four personalization tasks from the LaMP benchmark:

    LaMP-2: Movie Tagging Classification
    LaMP-3: Product Rating Classification
    LaMP-4: News Headline Generation
    LaMP-5: Scholarly Title Generation

Update the dataset and checkpoint paths in the configuration files under `configs/` as needed.

## Setup

Create the Conda environment:

```bash
conda env create -f environment.yml
conda activate mof
```

## Run

The full experimental pipeline is provided in `run.sh`.

Set the OpenAI API key path and configuration paths, then run:

```bash
bash run.sh
```

The pipeline includes:

    1. User representation extraction
    2. Cluster-based sampling
    3. Reranker training and evaluation
    4. Black-box LLM candidate generation
    5. Adapter data construction
    6. Adapter training and evaluation
